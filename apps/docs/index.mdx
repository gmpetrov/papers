## How Papers fits together

- **Workspaces** own inboxes, phone numbers, billing, and usage limits.
- **Credentials** define what an integration can do and which resources it can access.
- **Operations** track sends and number provisioning so you can handle retries without duplicating actions.
- **Approvals** let a person review an agent's action before it runs.
