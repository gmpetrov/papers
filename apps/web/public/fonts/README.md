# Reference typefaces

These WOFF2 subsets were extracted from the user-provided `/Users/gpetrov/Downloads/Design.html` reference on 2026-09-18. They are self-hosted to avoid runtime font-service dependencies.

- Newsreader: display headings and wordmark.
- Schibsted Grotesk: interface and body text.
- IBM Plex Mono: code, identifiers, labels, and tabular metadata.

The supplied files cover the Latin Unicode range declared in `src/app/fonts.css`; other characters use the declared fallback stack. Font licenses are included alongside the files.
