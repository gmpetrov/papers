# Grok custom MCP connector

The official [Grok connector documentation](https://docs.x.ai/grok/connectors) supports custom MCP servers. In Grok's connectors page, choose New Connector → Custom, enter the public MCP URL and complete authentication. Business/Enterprise deployments may first need an administrator to provision the connector. A custom connector is distinct from a preconfigured catalog listing.

For Papers development, use `https://dev.chaindesk.ai/mcp`. Sign in to Papers, select the workspace and consent to the required scopes. Run the shared review scenarios and verify that removing the connection in Papers blocks subsequent access. Record the tested Grok account/plan and date; no actual Grok session has been validated yet.

The official page inspected describes custom connection and the catalog but does not establish an open developer catalog submission process. Catalog onboarding remains unresolved; do not invent a submission endpoint or claim publication. Production hosting and actual client compatibility are still required.
