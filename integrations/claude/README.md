# Claude remote MCP connector

Submit the hosted MCP server through Claude's Connectors Directory portal. The official instructions require a Team/Enterprise organization with directory-management access. The portal collects HTTPS connection/authentication details, listing assets, support and privacy information, use cases, company details and reviewer access. Tools need titles and appropriate annotations; authenticated services use OAuth. See [official directory submission instructions](https://claude.com/docs/connectors/building/submission).

For development, connect a custom remote MCP connector to `https://dev.chaindesk.ai/mcp`, complete Papers consent and choose a workspace. Start with read scopes and run the shared review scenarios. Test actual Claude discovery, tool execution and revocation before claiming compatibility. No agent record is required in Papers.

The production endpoint, directory-authorized publisher account, policy/support URLs and reviewer account are not ready. No portal submission has been made. This is a remote connector; it is not an MCPB desktop-extension bundle or a Claude Code plugin archive.
